# Watch Out brand kit

Channel name: Watch Out
Tagline: Clips worth your time.
Colours: charcoal #101113, lime #D7F5A0, off-white #F1F1ED.

- watch-out-logo.png: 1024 x 1024, circle-crop friendly.
- watch-out-banner.png: 2560 x 1440. All lettering and the logo sit inside the central mobile-safe area (1544 x 422).
- watch-out-watermark.png: transparent 150 x 150, under 1 MB. Optional YouTube channel watermark; the Shorts already have their Watch Out watermark baked in.
- channel-description.txt: copy-ready description.
- SVG files: editable vector masters.

## Apply to YouTube

Open YouTube Studio for your intended channel, then Customization > Profile. Upload the logo and banner, set the name to Watch Out, paste the description, then Publish. Upload the optional channel watermark there too if desired.

Installing this gallery does not apply branding to a YouTube channel: Zernio's documented API provides posting but no YouTube channel-branding update endpoint. Its account display-name override does not update YouTube. A direct Google channel/banner API would require separate Google OAuth authorization.

Artwork provenance: eye/play concept developed with OpenAI image generation, then recreated as native vector masters for exact export dimensions. Original generated concepts are retained separately in the workspace. No font files or third-party logos are bundled.

Guidance: https://support.google.com/youtube/answer/10456525
